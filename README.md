# 同桌 · 多人云端协作 MVP

多人在网页里讨论、共享文件，显式 `@Agent` 请求分析。房主控制执行；每个房间对应一个 Codex 托管云任务，模型使用 Mac 上 Codex CLI 的 ChatGPT 订阅登录。

**当前状态：自动提交代码与隔离协议测试已完成，真实云端推理尚未验证。当前只能查询近期云任务中的环境标识，未接通 App 的环境目录或当前选择；不能把网页启动请求或模拟握手视为云端成功。** 当前运行证据见 [MVP-status.md](MVP-status.md)。

## 启动网页

需要 Node.js 22.13 或以上、官方 Codex CLI；无 npm 运行依赖。

先克隆项目。在 Mac 上准备好对外访问工具后，可双击 `启动同桌.command`，或者执行：

```sh
git clone https://github.com/wyq0721/tongzhuo.git
cd tongzhuo
npm run share
```

房主在 Mac 打开 <http://127.0.0.1:8796>。启动器会复用后台服务和可用的 Cloudflare 临时通道；关闭启动终端后服务继续运行。Mac 需要保持开机联网；Mac 重启后重新启动。只在本机体验用 `npm run up`。

新克隆不包含 `.local/bin/cloudflared`。`npm run share` 需要先将官方 cloudflared 可执行文件放入该位置；已有 HTTPS 反向代理时可运行 `npm run up` 并在连接设置填写其地址。

创建房间，点击「邀请同事」。受邀成员填写昵称和角色即可聊天；角色名称不授予房主权限。普通聊天不触发模型。

## 准备 Codex 云端环境

可以直接以本仓库的 `main` 分支准备环境。Node.js 22.13+、Python 3 即可，无 npm 运行依赖。准备步骤与验证命令见 [云端环境准备](docs/cloud-environment.md)。仓库源码不包含 Mac 房间数据库、文件和账号凭证。

## 复用已有环境

房主点击「启动 Agent」，服务使用已登录的官方 Codex CLI 查询近期云任务。只发现一个可用环境标识时自动绑定并提交；有多个时显示选择列表，点击名称即可使用。无需在常规流程填写环境 ID，也不要求重复新建环境。

**能力边界：这个来源是近期云任务记录，不是完整环境目录，也不能读取 Codex App 当前选中的环境。** 记录为空或未返回环境标识时，不能判断 App 没有环境。自动复用 App 当前选择这项目标尚未完成。

「选择已有环境」会自动查询并显示上述列表，网络错误和空结果分开提示。已有实际 ID 的用户仍可展开「高级」手工绑定；这保留为可选回退。当前目录由 CLI 默认使用 main，需要其他分支时在高级选项填写。

已绑定时，Mac 执行官方 `codex cloud exec --env … --attempts 1`。页面区分提交、任务创建和收到房间握手。没有使用本地模型替代云端。真实云端推理仍需实际任务验收。

官方依据：[开发命令](https://learn.chatgpt.com/docs/developer-commands#codex-cloud)、[App Server 协议](https://learn.chatgpt.com/docs/app-server)。本机 CLI 0.163.0 生成的公开及实验协议没有云端环境列表或 App 当前云端选择查询；`environment/info` 需要已知的执行环境标识，并不提供该列表。

## 讨论、文件与执行

- 直接聊天或上传文件不会触发 Agent；点击 `@Agent` 或以 `@Agent` 开头发言会生成请求。正文中间提到 `@Agent` 保持普通聊天。
- 房主发起的请求直接排队；成员发起的请求等待房主批准。未接入时请求保留，接通后领取，无需重复发送。
- 每轮请求固定截至触发消息的历史、发言人身份、角色、引用和勾选的附件版本。每个房间同时执行一个请求；云任务完成后继续等下一轮。
- 文件原件保存在 Mac，20 MB/文件，同名保留版本。云端通过房间授权下载原始字节并核对 SHA256；报告等产物以原始字节回传。
- 提交超时或服务在提交中重启时标记「启动结果待核实」，不会自动再次创建。只有房主检查云任务记录并确认未创建后才能解除待核实状态。
- 群聊在线与 Agent 在线分开显示。超过60秒未联系表示状态待确认，已经领取的请求不会自动重试。
- 一次房间连接有效30分钟。撤销会收回队列与文件访问权；远端已开始的命令仍需房主到 Codex 检查并停止。

公网访问必须转发到 Mac 服务，仅上传静态网页不能运行多人队列。Cloudflare Quick Tunnel 是临时开发入口，重建后域名可能变化；邀请接口使用当前已验证地址。后台日志在 `.local/server.log` 和 `.local/tunnel-*.log`。

## 验证与数据

```sh
npm run check
npm test
npm run build
```

接口测试使用临时数据库、真实回环 HTTP、Python 传输客户端和假的 CLI 可执行文件。覆盖房主权限、环境绑定、启动幂等、结果不确定、撤销竞态、重启恢复、同一会话两轮协议、文件原始字节与结果幂等。不会提交真实云任务。浏览器验证记录位于 `.local/qa/`。

`.local/` 包含 SQLite、文件和私有凭证，已忽略，不能上传到站点源码仓库。更换浏览器需重新通过邀请入场。源码入口：`server.mjs`、`cloud-runtime.mjs`、`public/`、`agent_client.py`；产品规格在 `docs/product-spec.md`。
